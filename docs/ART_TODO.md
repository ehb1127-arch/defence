# 만들어야 할 이미지 목록

파일을 이 경로에 넣기만 하면 게임이 자동으로 그림을 바꿉니다 (코드 수정 불필요).
없는 파일은 지금처럼 임시 그림(색만 바꾼 그림 또는 도형)으로 나옵니다.

**공통 스타일**: 지금 넣은 아트 세트와 같은 톤. 밝은 판타지, 2~3등신 캐릭터, 굵은 외곽선, 투명 배경 PNG.
캐릭터·적은 **정면 또는 약간 측면**, 그림 가장자리에 여백 없이 꽉 차게(단, 잘리지 않게).

우선순위: **P1** = 지금 가장 눈에 띄게 어색한 것, **P2** = 있으면 확 좋아지는 것, **P3** = 마무리.

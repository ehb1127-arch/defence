# 스토리 · 세계관 — 결계 수호대 (1부 사각 결계 연대기 · 2부 새 결계의 주인)

## 세계관

**사각 왕국 콰드라.** 천 년 전, 초대 수호자가 심연을 막기 위해 땅 위에 거대한 **사각 결계**를 새겼다.
심연에서 온 괴물들은 결계를 통과하지 못하고, 틈을 찾아 **결계의 테두리를 끝없이 맴돈다.**
테두리에 괴물이 너무 많이 쌓이면 결계는 무게를 이기지 못하고 깨진다.

결계를 지키는 이들을 **결계사**라 부른다. 결계사는 결계 안쪽 칸에 수호병을 불러내고,
같은 수호병을 합쳐 더 강한 존재로 만들며, 전설 속 **신화 수호자**를 불러낼 수 있다.
처음 전해진 다섯(불사조·뇌신·시간술사·황금왕·그림자군주)에 더해, 2부 무렵 여섯이 더 깨어났다
(대지거신·성기사·역병군주·천궁·빙룡·공허술사). 전설 수호병은 네 종뿐이라 한 판에 부를 수 있는 신화는 몇 명뿐이다.

> 게임 규칙과 1:1 로 대응합니다
> - 트랙을 도는 적 = 결계 틈을 찾는 괴물 / 적 수 한도 = 결계가 버티는 무게
> - 유닛 소환·합성·★ 강화 = 결계사의 수호병 / 신화 조합 = 신화 수호자 11명 (조합마다 전설 1명 필요)

**결말:** 사각의 군주를 넘어선 플레이어가 새 결계의 주인이 되고, 갇혀 있던 영혼들이 쉴 수 있게 된다. (1부 완결 → 무한 모드/대전으로 이어짐)

**2부 아이디어 (확장용):** 새 결계를 노리는 다른 심연 / 카엘의 배신 또는 합류 / 다섯 신화 수호자 각자의 과거 에피소드(유닛 스토리)

## 스테이지 구성

- 스테이지는 **6~12 라운드**의 짧은 판 (3~6분) → "한 판만 더"
- 장마다 적 체력 배수가 오르고, 시작 골드·보석도 늘어남
- 스테이지 규칙(모디파이어): 질주 · 철갑 · 풍요 · 대군 · 중장갑 · 운 봉인
- 평가: **★1** 클리어 / **★2** 최대 적 수 30 미만 / **★3** 최대 적 수 15 미만 + 부활 없이
  (최대 적 수에는 보스·중간보스 무게를 넣지 않는다 → 보스 스테이지도 ★3 가능, 장별 ★12 상자·스토리 ★135 달성 가능)
- 분열체·치유사: 무한 모드는 16·22라운드부터, 스테이지는 장이 깊을수록 일찍 (4장 6라운드~, 6장 1라운드~, 탑은 층이 높을수록, 오늘의 결계 2라운드~, 악몽은 더 일찍)
- 장별 **★ 상자** (★4 / ★8 / ★12): 코인 + 아이템

## 2부 · 새 결계의 주인 (6~10장, 25스테이지)

"결계는 괴물만이 아니라 모두를 가둔다"며 각 지역의 수호자들을 타락시킨다.

| 인물 | 역할 |
| --- | --- |
| **미라** | 심연의 무녀. 카엘을 키운 사람. 결계 없는 세상을 약속하며 수호자들을 타락시키지만, 마지막엔 결계 안에서 살고 싶었다고 고백 |
| **서리 여제 / 모래 폭군 / 세라프 / 녹스** | 각 장의 보스. 쓰러진 뒤 결계의 숨은 역사(원형 결계, 천사, 그림자)를 알려주고, 최종장에서 동료로 돌아옴 |

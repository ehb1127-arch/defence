# 효과 이미지 가이드 (스킬·타격·보스 기술)

지금 모든 효과는 코드로 그립니다. 아래 파일을 `art/fx/` 에 넣으면 **그 효과만 자동으로 이미지로 바뀝니다** (코드 연결 완료, 수정 불필요).
없는 파일은 지금처럼 코드 효과로 나오니 **우선순위 높은 것부터 조금씩** 넣으셔도 됩니다.
- 신화 스킬·보스 기술 이미지가 있으면 그 순간의 코드 효과는 꺼지고 이미지만 나옵니다 (피해·빙결 등 게임 효과는 그대로)
- 원거리 공격(화살·불덩이 등)의 타격 이미지는 `proj_<종류>.png` 투사체 이미지가 **함께 있을 때만** 쓰입니다 (근접은 타격 이미지만 있으면 됨)
- 검은 배경 그림은 자동으로 검정을 투명으로 바꿉니다
---

## 1. 두 가지 방식 — 편한 쪽으로

| 방식 | 파일 이름 | 설명 | 추천 |
| --- | --- | --- | --- |
| **A. 한 장 그림** | `<이름>.png` | 효과가 가장 화려한 순간 **한 장**. 게임이 커지기·회전·번쩍임·사라짐을 코드로 입혀 움직이게 함 | ✅ AI 이미지로 만들기 쉬움. **먼저 이걸로** |
| **B. 프레임 시트** | `<이름>_sheet.png` | 4×4 칸 = **16프레임** 애니메이션 | 더 자연스럽지만 프레임끼리 모양이 이어져야 해서 만들기 어려움 |

둘 다 있으면 B(시트)를 씁니다.

## 2. 공통 규칙

- **PNG, 투명 배경**. 검은 배경 X (게임이 밝게 더하기 합성을 하므로 빛·불꽃은 투명 배경에 밝은 색으로)
- **정사각형**, 효과의 **중심이 그림 한가운데**
- 가장자리에서 잘리지 않게 사방에 5~10% 여백
- 한 장 그림(A): **512×512**
- 프레임 시트(B): **1024×1024** (한 칸 256×256), 순서는 **왼쪽→오른쪽, 위→아래**. 1번 칸 = 시작(작게), 16번 칸 = 끝(흩어져 사라짐)
- 게임 화면에서는 효과 범위에 맞춰 크기가 자동 조절됨 (작게 보여도 알아볼 수 있게 **굵고 대비 강하게**)
- **흰색/밝은 회색으로 그리라고 적힌 것**은 게임이 유닛 색으로 물들여 씁니다 (한 그림으로 여러 색)

## 3. P1 · 신화 스킬 11종 — 가장 눈에 띄는 것

| `skill_timestop` | 시간 정지 (시간술사) | 금빛 톱니 시계 문양 마법진, 시곗바늘, 옥색 빛 |
| `skill_goldrain` | 황금비 (황금왕) | 쏟아지는 금화 한 무더기 + 반짝임, 금색 |
| `skill_reap` | 영혼 수확 (그림자군주) | 크게 휘두른 보라빛 낫 궤적 + 빠져나가는 영혼 |
| `skill_quake` | 대지 강타 (대지거신) | 갈라지는 땅, 튀는 바위 조각, 먼지 고리, 갈색·주황 |
| `skill_bless` | 신성 축복 (성기사) | 위에서 내려오는 빛기둥 + 날개 모양 빛, 금·흰색 |
| `skill_plague` | 역병 확산 (역병군주) | 퍼지는 초록 독안개 구름 + 해골 모양 연기 |
| `skill_arrowrain` | 화살비 (천궁) | 위에서 쏟아지는 빛 화살 여러 개, 옥색 바람 |
| `skill_breath` | 빙결 숨결 (빙룡) | 옆으로 길게 뿜는 서리 숨결 (**가로로 긴 모양, 왼→오른쪽**), 하늘색·흰색 |
| `skill_blackhole` | 블랙홀 (공허술사) | 빨려 드는 보라빛 소용돌이, 가운데 검은 구멍, 별가루 |

## 5. P2 · 공격 타격 효과

유닛이 적을 때릴 때 적 위에 터지는 짧은 효과. **흰색/밝은 회색으로** 그리면 유닛 색이 입혀집니다.
파일: `art/fx/hit_<종류>.png` (256×256이면 충분, 시트는 512×512 = 한 칸 128)

| 파일 | 쓰는 유닛 | 모양 |
| --- | --- | --- |
| `hit_slash` | 검사·도끼 | 초승달 모양 베기 궤적 |
| `hit_stab` | 단검·창 | 날카로운 찌르기 섬광 (가로 방향) |
| `hit_bash` | 방패·망치 | 둥근 충격 파문 + 별 |
| `hit_arrow` | 궁수·저격 | 박히는 화살 섬광 |
| `hit_fire` | 불 계열 | 작은 불꽃 폭발 (**이건 주황색으로**) |
| `hit_ice` | 얼음술사 | 깨지는 얼음 파편 (**하늘색으로**) |
| `hit_zap` | 번개 | 짧게 튀는 전기 (**노랑·흰색으로**) |
| `hit_holy` | 성직자 | 십자 모양 빛 |
| `hit_poison` | 연금술사 | 튀는 독 방울 (**초록으로**) |
| `hit_magic` | 마법사·음유시인 | 둥근 마법 파동 + 반짝이 |

날아가는 투사체(화살·불덩이 등)를 이미지로 하고 싶으면: `art/fx/proj_<종류>.png` 128×128, **오른쪽을 향하게** (게임이 날아가는 방향으로 회전).

## 6. P2 · 연출

| 파일 | 언제 | 모양 |
| --- | --- | --- |
| `summon_legend` | 전설·신화 소환 | 위로 솟는 금빛 빛기둥 + 별 |

작게 보이므로 **128×128**, 단순하고 굵게. 시트로 만들면 반복 재생 (16프레임이 자연스럽게 1번으로 이어지게).

| 파일 | 상태 | 모양 |
| --- | --- | --- |
| `status_freeze` | 빙결 | 적을 가두는 얼음 덩어리 (가운데 비움) |

| `status_stun` | 기절 | 머리 위 도는 별 3개 |
| `status_burn` | 화상 | 작은 불꽃 |
| `status_poison` | 중독 | 초록 거품 |

## 만들기 팁

- AI 이미지로 만들 때: *"game VFX, magic effect, isolated on transparent background, centered, top-down view, bright glow, cartoon fantasy style"* + 위 설명
- 배경을 투명으로 못 뽑으면 **순수 검은 배경**으로 만들어 주세요 — 검정을 투명으로 바꿔서 쓰겠습니다
- 한 번에 다 할 필요 없어요. **추천 순서**: 신화 스킬 11 → 보스 기술 12 → `boss_death`·`summon_legend` → 나머지
- 몇 개만 먼저 넣어 주시면 게임에 연결해서 화면으로 보여드리고, 크기·밝기 느낌을 맞춘 뒤 나머지를 만드시면 효율적입니다

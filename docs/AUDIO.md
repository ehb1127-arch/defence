# 배경음악 · 효과음

지금 들어 있는 소리는 모두 `tools/make_audio.py` 로 **직접 작곡·합성한 원본**입니다 (저작권 걱정 없음).
다시 만들려면: `python3 tools/make_audio.py` (numpy 필요) → `audio/bgm/*.wav`, `audio/sfx/*.wav`

## 배경음악 (반복 재생, 화면이 바뀌면 부드럽게 넘어감)

| 파일 | 나오는 곳 | 분위기 |
| --- | --- | --- |
| `audio/bgm/lobby` | 로비·상점·도감 | 밝고 당당한 모험 테마 (96 BPM) |
| `audio/bgm/map` | 스토리 지도, 판이 끝난 뒤 결과 화면 | 잔잔한 종소리 (84 BPM) |
| `audio/bgm/battle` | 전투 중 | 빠르고 긴장감 있는 전투 곡 (132 BPM) |
| `audio/bgm/boss` | 보스·중간보스가 살아 있는 동안 | 금관 + 강한 북 (150 BPM) |

## 효과음 21개 (`audio/sfx/`)

| 이름 | 언제 |
| --- | --- |
| `click` | 버튼 누름 |
| `summon` · `rare` · `legend` | 소환 (일반 / 희귀·영웅 / 전설 이상·합성 대성공·보스 처치) |
| `merge` · `fail` | 합성·강화 성공 / 실패 |
| `hit` · `ice` · `zap` · `boom` | 공격 타격 / 얼음 / 번개 / 폭발(신화 스킬·보스 기술·보스 처치) |
| `coin` · `reward` | 골드 날아감 / 보상 (위기 극복·잭팟·중간보스 처치) |
| `round` · `boss` · `alarm` · `heart` | 라운드 시작 / 보스 등장 / 위기·한도 경고 / 한도 임박 심장 박동 |
| `tick` · `tick_boss` | 카운트다운 |
| `fever` | 피버 발동 |
| `win` · `lose` | 판 승리 / 패배 음악 (이때는 배경음악이 잠깐 멈춤) |

## 전문 음원으로 바꾸고 싶다면

같은 이름으로 파일만 넣으면 코드 수정 없이 바뀝니다.

- 배경음악: `audio/bgm/battle.ogg` 처럼 **.ogg** (또는 .mp3) 를 넣으면 .wav 보다 먼저 씁니다. 자동으로 반복 재생.
  - 1~2분 길이, 끝과 시작이 자연스럽게 이어지게 (루프용으로 만든 곡)
- 효과음: `audio/sfx/legend.ogg` 처럼 **.ogg** 를 넣으면 먼저 씁니다. 0.1~1.5초, 앞에 무음 없이.
- 음악/효과음 끄기: 로비 → 설정 → `배경음악` / `효과음`. 전투 중 소리 버튼은 둘 다 한 번에 끄고 켭니다.

용량: 배경음악은 게임 안에서 QOA 로 압축되어 4곡 합쳐 약 1.8MB 입니다.

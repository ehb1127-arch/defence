# 재화 / 계정 서버 저장

코인·아이템·강화·스테이지 ★·업적·일일 미션 등 **계정 재화는 전용 서버(OCI)가 기준**입니다.

## 구조

```
클라이언트 (Profile.gd)                      전용 서버 (Net.gd)
─────────────────────────                    ─────────────────────────────────────
버튼 → Profile.buy_item("x")                  계정마다 Profile.gd 인스턴스(server_side=true)
  ① 로컬에서 바로 반영 (반응 빠름)
  ② sync("buy_item", ["x"]) ───────────────▶ _s_op: 같은 함수 run_op("buy_item", ["x"]) 실행
                                              server_db.json 에 저장
  ③ apply_server(서버 값) ◀──────────────── _c_op(req_id, 결과, 계정 전체)
     → 로컬 파일을 서버 값으로 덮어씀
```

- **같은 규칙 코드(Profile.gd)를 서버와 클라이언트가 같이 씁니다.** 규칙을 바꾸면 서버도 같은 빌드로 재배포.
- 서버가 허용하는 작업은 `Profile.OPS` 목록뿐 (`buy_item`, `buy_perk`, `level_up_unit`, `claim_daily`, `attend`,
  `claim_chest`, `claim_idle`, `use_item`, `take_loadout`, `ad_reward`, `roulette`, `match_end` …).
- 결과가 난수인 작업(룰렛, 광고 랜덤 아이템)은 `await Profile.request(...)` 로 **서버 결과를 기다립니다**.
- 로컬 파일을 고쳐도 다음 서버 응답에서 서버 값으로 돌아갑니다 (`tests/econ_test.gd` 로 확인).

## 판 정산

게임 계산은 클라이언트가 하므로 판 결과는 **요약(summary)** 으로 보냅니다 (`Match._match_summary()`).
서버는 `Profile.validate_summary()` 로 상한을 검사합니다:

- 라운드 ≤ 최종 라운드+5, 처치 수 ≤ 라운드×45+20, 스테이지는 해금된 것만, 승리는 마지막 라운드까지 간 경우만
- 신화/보스/합성 수 상한, 도감은 실제 있는 유닛만, 광고 2배는 하루 광고 한도 안에서만
- 판 정산은 **최대 10회 몰아서 + 60초마다 1회** (오프라인 판 재전송 허용, 무한 반복 차단)

> 완전한 검증(서버가 게임을 다시 계산)은 아니므로, 이득을 "한 판에 받을 수 있는 최대치"로 제한하는 방식입니다.

## 첫 접속 (계정 이전)

서버에 계정 재화가 없으면 기기 진행을 한 번 올려 받습니다 (`Net.sanitize_migration`).
조작 방지를 위해 코인 ≤ 5000, 레벨 ≤ 30, 아이템 ≤ 10개, 기록 상한, 결제 상품(광고 제거 등)은 옮기지 않음,
옮긴 기록으로 이미 도달한 업적은 "받은 것"으로 처리합니다.

## 오프라인

- 서버 계정과 연결된 적 있는 기기(`Profile.linked`)는 오프라인에서도 플레이 가능.
  작업은 `pending_ops` 에 쌓였다가 **다음 접속 때 순서대로 서버에 재전송**됩니다 (최대 200개).
- 서버에 한 번도 접속하지 않은 기기는 순수 로컬 저장 (싱글 전용).
- 메뉴에 들어오면 `Net.server_address` 로 조용히 접속합니다 (설정 > "시작할 때 서버 계정과 동기화").
  `Net.DEFAULT_SERVER` 를 OCI 서버 주소(`wss://도메인`)로 바꿔서 빌드하세요.

## 계정 식별

지금은 기기에서 만든 무작위 `device_id` 가 계정 키입니다. 앱을 지우면 새 계정이 됩니다.
출시 전 권장: **Google Play 게임즈 로그인**(서버 인증 코드 → 서버에서 확인)으로 계정 키를 바꾸기.
`Net._s_hello` 의 `device_id` 자리를 검증된 플레이어 ID 로 바꾸면 나머지는 그대로 동작합니다.

## 저장 파일 (서버)

| 파일 | 내용 |
| --- | --- |
| `server_db.json` | 기기(계정)별 이름·레이팅·전적 + `profile`(재화 전체) |
| `server_iap.json` | 사용한 결제 영수증 (중복 지급 방지) |

위치: `~/.local/share/godot/app_userdata/사각 디펜스 (Square Defense)/` — **정기 백업 필수** (docs/OCI_DEPLOY.md).

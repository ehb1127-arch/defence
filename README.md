# 사각 디펜스 (Square Defense)

Godot 4 로 만든 **스타크래프트 유즈맵 스타일 사각형 디펜스**입니다. 적은 모서리에서 쏟아져 나와
사각형 테두리 길을 계속 돌고, 플레이어는 사각형 **안쪽 칸**에 유닛을 소환·합성·조합해서 막아냅니다.
라운드는 시간이 되면 무조건 넘어가고, 보스는 **제한시간 안에 못 잡으면 즉시 패배**합니다.
솔로, **협동**, **대전**을 AI / 한 화면 2인 / **온라인(OCI 전용 서버 또는 LAN)** 으로 즐길 수 있습니다.

## 실행

1. [Godot 4.3 이상](https://godotengine.org/download) 설치 (표준 버전, .NET 필요 없음)
2. Godot 에서 이 폴더의 `project.godot` 열기 → F5 (실행)

외부 에셋 없이 모든 그래픽과 효과음을 코드로 만듭니다. 폰트는 나눔스퀘어라운드(OFL)를 포함했습니다.

## 게임 모드

| 모드 | 설명 |
| --- | --- |
| 솔로 | 40라운드를 혼자 막기. 40라운드 최종 보스를 잡으면 승리 |
| 협동 (AI / 로컬 2인 / 온라인) | 두 전장의 **적 수 합계 180** 이 한도, 한 명이라도 보스를 놓치면 패배. 골드·유닛 선물, 합동 폭격 |
| 대전 (AI / 로컬 2인 / 온라인) | 각자 한도 100. 상대에게 적을 보내고 저주를 걸어 먼저 무너뜨리기 |

### 온라인

- **전용 서버(OCI)**: 메뉴 오른쪽 **온라인** → 서버 주소 입력 → **접속** → 방 목록에서 참가 / 방 만들기 / **빠른 매칭**
- **LAN**: 한 명이 **이 PC 에서 서버 열기** → 방 만들기, 친구는 그 PC 의 IP 로 접속
- 매치가 끝나면 방에 남아 **재대결** 가능. 통신은 WebSocket, 기본 포트 TCP `24680`
- 서버 설치: [docs/OCI_DEPLOY.md](docs/OCI_DEPLOY.md) (`sudo bash deploy/oci/install.sh` 한 줄)
- 메시지 명세: [docs/PROTOCOL.md](docs/PROTOCOL.md)

## 핵심 규칙

- 사각형 안쪽은 **6×6 격자**로 꽉 차 있고, 라운드·남은 시간은 화면 **상단 바**에 크게 표시됩니다
- 필드 위 적이 한도(기본 100)에 도달하면 패배. 적은 라운드마다 20마리씩 모서리에서 줄지어 나와 트랙을 돕니다
- **20초마다 다음 라운드** (못 잡은 적은 계속 쌓임). 마지막 5초는 큰 카운트다운
- **10라운드마다 보스**: 60초(최종 40라운드 보스는 90초) 안에 못 잡으면 **즉시 패배**
- **보너스 라운드**(5·15·25·35): 25초 안에 보물 돼지를 잡아 골드 획득, 전부 잡으면 보석
- **소환**: 골드로 무작위 유닛(일반/희귀/영웅/전설). 소환할수록 비용 +1. 같은 유닛은 한 칸에 3마리까지 쌓임
- **합성**: 같은 유닛 3마리가 쌓인 칸 → 한 단계 위 등급 무작위 유닛
- **신화 조합**: 정해진 재료를 모으면 신화 유닛 (자동 발동 스킬 보유)

| 신화 | 재료 | 스킬 |
| --- | --- | --- |
| 불사조 | 화염술사 x2 + 광전사 + 용기사 | 화염 폭풍: 사거리 내 전체 5배 피해 |
| 뇌신 | 번개술사 x2 + 저격수 + 대마법사 | 천둥 심판: 필드 전체 번개 + 기절 |
| 시간술사 | 얼음술사 x2 + 음유시인 + 수호천사 | 시간 정지: 모든 적 2.5초 정지 |
| 황금왕 | 도적 x3 + 연금술사 + 암살자 | 황금비: 보유 골드 10% 이자 |
| 그림자군주 | 기사 x2 + 사냥꾼 + 암살자 | 영혼 수확: 체력 높은 적 3명 즉사 |

## 재미 요소

- **도박**: 보석으로 영웅(60%) / 전설(25%) 뽑기. 실패하면 "꽝!", 3연속 실패하면 위로 과제 보상
- **강화**: 등급군별 공격력(+12%/Lv), 소환 행운(고등급 확률 증가)
- **배치 전략**: 유닛마다 사거리가 달라 칸 위치가 중요. 음유시인은 주변 8칸 공속 버프, 수호천사는 사거리 내 적 둔화
- **랜덤 이벤트**(3·8·13… 라운드): 황금 고블린, 행운의 시간(소환 반값), 광란, 보급품(무료 소환), 번개 폭풍, 보석비
- **보물상자**: 적 처치 시 가끔 떨어짐. 클릭해서 골드/보석/무료 소환/영웅 유닛
- **도전 과제** 8종, 게임 종료 시 **MVP 유닛** (피해량 순위)
- 협동: 골드 선물, **유닛 선물**(조합 재료 몰아주기), 처치 게이지로 두 전장 동시 **합동 폭격**
- 대전: **잡몹 떼**, **정예 괴수**, **저주**(상대 공속 -30%) 보내기. 40라운드 이후 적이 급격히 강해지는 연장전
- 유즈맵 느낌의 효과음: 라운드 시작, 카운트다운 삑, 보스 경보, 한도 임박 경보, 고등급 획득

## 상점 · 광고 보상

- 판이 끝나면 **코인**을 받습니다 (라운드·처치 수·승리 보너스). 결과 화면에서 **광고 보고 2배**
- **상점**(메인 메뉴 오른쪽 위)
  - 아이템: 골드 주머니, 보석 상자, 소환권, 행운 부적 → "다음 판에 사용" 켜두면 시작할 때 자동 적용 / 부활 깃털 → 패배 시 부활
  - 영구 강화: 시작 골드, 보물상자 확률, 도박 성공률, 보스 제한시간 (각 5레벨)
  - 무료 보상: 광고 보고 코인 / 랜덤 아이템 (하루 8회)
- 게임 중: **광고 보고 무료 소환 3회**, 패배 시 **광고 보고 부활** (각 판당 1회, 솔로·로컬 협동)
- 대전에서는 공정성을 위해 아이템·영구 강화·게임 중 광고가 적용되지 않습니다
- 광고는 현재 테스트 광고로 동작하며, 실제 AdMob 연결 방법은 [docs/ADS.md](docs/ADS.md)

## 그림 교체 (아트 작업)

모든 유닛·적·아이콘·버튼·패널·배경은 `art/` 폴더에 **정해진 이름의 PNG 를 넣기만 하면** 자동으로 교체됩니다.
없으면 코드로 그린 임시 그림(유닛별 고유 문양)이 나옵니다. 파일 목록과 권장 크기: [art/README.md](art/README.md)

- 전장에는 글자를 쓰지 않습니다 (유닛은 문양/이미지로 구분, 이름은 마우스 오버·선택 시에만)
- 버튼은 아이콘 + 숫자(비용) 중심, 설명은 툴팁. 설정에서 "버튼 이름 표시"를 켜면 작은 이름이 나옵니다

## 조작

- 마우스: 칸 클릭 → 다른 칸 클릭으로 이동/교체(같은 유닛이면 합치기), 우클릭 선택 해제. 모든 행동은 하단/우측 아이콘 버튼
- 도박·강화·조합·공격·협동·과제 버튼은 전장 위에 카드 팝업을 엽니다 (Esc 로 닫기)
- 1P 키보드: `WASD` 커서, `Space` 선택, `Q` 소환, `E` 합성, `R` 영웅 도박, `T` 신화 조합, `F` 공격/폭격, `X` 판매
- 2P 키보드: 방향키 커서, `Enter` 선택, `U` 소환, `I` 합성, `O` 영웅 도박, `P` 신화 조합, `L` 공격/폭격, `K` 판매 (숫자패드 `1~5`, `0` 도 가능)
- `Esc` 일시정지, 배속 x1/x2/x3 (온라인 제외)

## 구조

```
scripts/autoload/GameData.gd  유닛·조합식·적·라운드·경제 수치, UI 테마 (밸런스는 여기서 조정)
scripts/autoload/Session.gd   선택한 모드/참가자 보관
scripts/autoload/Net.gd       온라인(WebSocket): 전용 서버 / LAN 호스트 / 클라이언트 - 방·매칭·중계
scripts/autoload/Sfx.gd       코드로 생성하는 효과음
scripts/autoload/Art.gd       그림 교체 지점 (art/ 에 PNG 가 있으면 사용)
scripts/autoload/Profile.gd   코인·아이템·영구 강화·설정·기록 저장 (user://profile.cfg)
scripts/autoload/Ads.gd       보상형 광고 (현재 테스트 광고, 네이티브 연결 자리)
scripts/ui/Glyphs.gd          이미지 없을 때 쓰는 벡터 아이콘/유닛 문양
scripts/ui/ActionButton.gd    아이콘 + 비용 뱃지 버튼
scripts/ui/Shop.gd            상점 화면
scripts/server/ServerMain.gd  전용 서버 모드 상태 로그
deploy/oci/                   OCI 설치 스크립트, systemd 서비스, Caddy(wss) 예시
docs/                         OCI 배포 가이드, 온라인 프로토콜
scripts/game/Board.gd         전장 하나: 시뮬레이션, 그리기, 플레이어 행동 API
scripts/game/Enemy.gd         적 상태
scripts/game/Bot.gd           AI 플레이어 (Board API 만 사용)
scripts/game/Match.gd         한 판: 레이아웃, 승패 규칙, 입력, 전장 간 상호작용, 네트워크
scripts/ui/BoardHUD.gd        전장별 조작 패널
scripts/ui/MainMenu.gd        메인 메뉴 / 로비 / 게임 방법
```

온라인은 각 플레이어가 **자기 전장만** 시뮬레이션하고, 상대 전장은 스냅샷으로 그립니다.
서버는 같은 방 두 사람 사이에서 스냅샷과 이벤트(적 보내기·선물·폭격·패배)를 중계만 하므로 가볍고,
같은 Godot 프로젝트를 `--server` 로 실행하면 그대로 서버가 됩니다.

## 테스트

```bash
# 봇끼리 빠르게 게임을 돌려 밸런스 확인 (모드, AI 레벨 0~2, 판 수)
godot --headless res://tests/SimTest.tscn -- solo 1 4
godot --headless res://tests/SimTest.tscn -- pvp 1 3

# UI 포함 스모크 테스트 (모드, 초, 스크린샷 폴더, 시간 배율)
godot res://tests/MatchSmoke.tscn -- coop 20 /tmp/shots 4

# 전용 서버 실행 (로컬)
godot --headless --path . -- --server --port 24680

# 온라인 테스트: 서버 + 빠른 매칭 클라이언트 2개 (각각 다른 터미널)
godot --headless res://scenes/Main.tscn -- --server --port 24690
godot --headless res://tests/NetTest.tscn -- quick pvp 20 127.0.0.1:24690
godot --headless res://tests/NetTest.tscn -- quick pvp 20 127.0.0.1:24690

# LAN 호스트 + 게스트
godot --headless res://tests/NetTest.tscn -- lanhost coop 20 24691
godot --headless res://tests/NetTest.tscn -- languest coop 20 127.0.0.1:24691
```
